# Desktop feature

Camada responsavel pela experiencia Windows XP: boot, login, desktop, taskbar, icones, janelas e registro dos apps.

Repos planejados:

- `Cyanoxide/react-xp`: boot e login.
- `ShizukuIchi/winXP`: desktop, taskbar, janelas e base de apps.
- `captbaritone/webamp`: Winamp como dependencia.
